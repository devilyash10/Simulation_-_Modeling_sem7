# **Introduction to Static and Dynamic System Simulation**

## **1. Introduction**

System simulation is the process of creating and experimenting with a model of a real-world system to understand its behaviour under different conditions.

Depending on whether the system's behaviour changes with time, simulation can be classified into two main types:

1. **Static System Simulation**
2. **Dynamic System Simulation**

## **2. Static System Simulation**

**Definition:** Static system simulation is a type of simulation in which the system is studied at a particular point in time. It does not consider how the system changes over time.

It represents a system under fixed conditions. The main focus is on the relationship between different variables rather than their changes over time.

**Examples:**

- Calculating the profit of a company using its revenue and expenses.
- Estimating the total cost of a manufacturing process.
- Calculating the probability of winning a game using random numbers.

**Characteristics:**

- Time is not an important factor.
- The system is studied at a particular point or under fixed conditions.
- It generally uses mathematical equations and statistical methods.
- It is useful for analysing situations that do not involve time-dependent changes.

## **3. Dynamic System Simulation**

**Definition:** Dynamic system simulation is a type of simulation in which the behaviour of a system is studied over a period of time. It considers how the system's state changes as time progresses.

It helps us understand how a system behaves in different time periods and how one event affects future conditions.

**Examples:**

- Studying the movement of vehicles in traffic over time.
- Simulating the temperature changes in a room.
- Studying customers arriving and waiting in a bank queue.
- Analysing the growth of a population over several years.

**Characteristics:**

- Time plays an important role.
- The system's state changes over time.
- It considers events and activities occurring during a period.
- It is useful for studying real-world systems whose behaviour changes with time.

## **4. Difference Between Static and Dynamic System Simulation**

| Static System Simulation                                          | Dynamic System Simulation               |
| ----------------------------------------------------------------- | --------------------------------------- |
| Studies a system at a particular point or under fixed conditions. | Studies a system over a period of time. |
| Time is not considered explicitly.                                | Time is an important factor.            |
| System conditions remain fixed during the analysis.               | System conditions can change over time. |
| Generally simpler to develop.                                     | Generally more complex to develop.      |
| Example: Calculating company profit.                              | Example: Simulating traffic movement.   |

## **5. Simple Example to Understand**

Consider a bank:

- **Static simulation:** Calculate the average number of customers present in the bank at a particular moment under given conditions.
- **Dynamic simulation:** Simulate customers arriving, waiting in queues, receiving services and leaving the bank throughout the day.

The first focuses on a fixed situation, whereas the second studies how the situation changes over time.

## **6. Important Points for Exams**

- Static simulation does not explicitly consider the passage of time.
- Dynamic simulation studies the behaviour of a system over time.
- Static simulation is generally used for fixed-condition analysis.
- Dynamic simulation is useful for studying changing systems.
- Bank queues, traffic systems and population growth are common examples of dynamic simulation.
