# **Module I – Introduction to Modeling and Simulation**

## **5. Static and Dynamic Physical Models**

### **5.1 Introduction**

Physical models are tangible representations of real-world objects or systems. They are created to understand the structure, appearance, design or behaviour of an actual system.

Based on whether they represent a system at rest or show changes over time, physical models can be classified into **Static Physical Models** and **Dynamic Physical Models**.

### **5.2 Static Physical Models**

**Definition:**

A static physical model represents a real-world object or system in a fixed condition at a particular point in time. It does not demonstrate the actual movement or changes in the system over time.

These models are mainly used to study the structure, shape, size and arrangement of different components of an object.

**Examples:**

1. **Building Model:** A miniature model of a building used by architects to understand its design and structure.
2. **Globe:** A physical representation of the Earth showing continents, oceans and geographical features.
3. **Bridge Model:** A miniature bridge used to understand its design and structural arrangement.

### **5.3 Dynamic Physical Models**

**Definition:**

A dynamic physical model represents a real-world system in which movement, changes or activities can be observed over time. Unlike static models, these models demonstrate how different components of a system behave or interact during operation.

They are useful for studying the working process and physical behaviour of actual systems.

**Examples:**

1. **Working Model of an Engine:** Demonstrates the movement of pistons and other engine components during operation.
2. **Hydraulic Model:** Represents the flow of water through pipes, channels or dams.
3. **Moving Mechanical Model:** Demonstrates the movement and interaction of gears, wheels and other mechanical components.

### **5.4 Difference Between Static and Dynamic Physical Models**

| Basis     | Static Physical Model                      | Dynamic Physical Model                           |
| --------- | ------------------------------------------ | ------------------------------------------------ |
| Meaning   | Represents an object in a fixed condition. | Represents a system showing movement or changes. |
| Behaviour | Does not demonstrate operation over time.  | Demonstrates operation and behaviour over time.  |
| Purpose   | Studies structure, shape and design.       | Studies movement and functioning.                |
| Time      | Represents a particular condition.         | Represents changes over time.                    |
| Example   | Miniature building model.                  | Working engine model.                            |

### **5.5 Quick Revision 📝**

- **Static Physical Model:** Shows how something looks or is structured.
- **Dynamic Physical Model:** Shows how something moves or works.

**Easy trick to remember:**

Static = Still (Building model).

Dynamic = Moving (Working engine model).
