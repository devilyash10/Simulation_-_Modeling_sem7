# **Module I – Introduction to Modeling and Simulation**

## **7. Concept of Simulation**

### **7.1 Definition**

Simulation is the process of creating a model of a real-world system and performing experiments on that model to understand, analyse and predict the behaviour of the actual system.

In simple words, simulation means imitating the working of a real system using a model. It allows us to experiment with different conditions without disturbing the actual system.

### **7.2 Concept of Simulation**

The main concept of simulation is to study how a real-world system behaves under different conditions by using a model.

Instead of performing experiments on an actual system, we create a model, provide input data and observe the results. By changing the input values, we can understand how the system will behave in different situations.

**Example – Banking System:**

Suppose a bank wants to reduce customer waiting time. Instead of experimenting with actual customers, it creates a simulation model containing customer arrival rates, service times and the number of cashiers.

By running different experiments, the bank can determine how many cashiers are required to reduce waiting time.

### **7.3 Steps Involved in Simulation**

1. **Define the Problem:** Identify the real-world problem that needs to be studied.
2. **Develop a Model:** Create a simplified representation of the actual system.
3. **Collect Input Data:** Gather the required information, such as arrival time and service time.
4. **Run Simulation:** Execute the model under different conditions.
5. **Analyse Results:** Study the output and understand the system's behaviour.
6. **Make Decisions:** Use the results to improve the actual system.

### **7.4 Applications of Simulation**

- **Banking:** Studying customer waiting times and cashier utilization.
- **Healthcare:** Analysing patient arrivals and hospital resources.
- **Computer Networks:** Studying packet transmission, network traffic and delays.
- **Transportation:** Analysing traffic congestion and vehicle movement.
- **Manufacturing:** Improving production processes and machine utilization.
