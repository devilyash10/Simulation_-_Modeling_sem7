# **Module I – Introduction to Modeling and Simulation**

## **3. System Modeling**

### **3.1 Introduction to System Modeling**

System modeling is the process of creating a simplified representation of a real-world system to understand its structure, working and behaviour.

A real-world system can be very complex, so instead of studying every detail, we represent only the important components and their relationships. This makes the system easier to understand, analyse and simulate.

**Example:** To study a banking system, we create a model containing customers, cashiers, arrival times and service times instead of representing every detail of the actual bank.

### **3.2 Steps Involved in System Modeling**

System modeling generally involves the following steps:

1\. **Identify the System:** First, identify the real-world system that needs to be studied and understand its purpose.

2\. **Identify Important Components:** Determine the important elements, variables and activities of the system.

3\. **Define Relationships:** Identify how different components interact with each other and how one component affects another.

4\. **Develop the Model:** Create a mathematical, logical or computer-based representation of the system.

5\. **Test the Model:** Check whether the model correctly represents the important behaviour of the actual system.

6\. **Analyse the Model:** Study the model under different conditions to understand and predict system behaviour.

### **3.3 Types of System Models**

System models can be classified into different types depending on how they represent a real-world system.

**1. Physical Models:**

Physical models are tangible representations of actual systems. They are usually smaller or simplified versions of real objects and can be physically observed.

*Example:* A miniature building model used by architects before constructing an actual building.

**2. Mathematical Models:**

Mathematical models represent a system using mathematical equations, formulas and relationships between variables. They help calculate and predict the behaviour of a system.

*Example:* Mathematical equations used to calculate the speed and distance of a moving vehicle.

**3. Computer Models:**

Computer models represent systems using computer programs and algorithms. They are useful for studying complex systems and performing experiments that may be difficult to conduct in real life.

*Example:* A computer program that simulates traffic movement at a road intersection.

### **3.4 Importance of System Modeling**

- **Simplification:** It reduces the complexity of real-world systems by representing only important components.
- **Understanding:** It helps us understand how different components interact and affect the overall system.
- **Prediction:** It helps predict the possible behaviour and outcomes of a system.
- **Cost Reduction:** It reduces the need for expensive experiments on actual systems.
- **Decision-Making:** It helps compare different alternatives before implementing changes in the real system.

**Remember:** System modeling is the process of creating a representation of a real-world system so that its behaviour can be studied and analysed easily.

## **4. Principles Used in Modeling**

### **4.1 Introduction**

Principles of modeling are the basic guidelines or rules that should be followed while developing a model of a real-world system.

These principles help ensure that the model is simple, accurate, understandable and suitable for the purpose for which it is created.

### **4.2 Important Principles of Modeling**

**1. Simplicity:**

A model should be as simple as possible while representing the important characteristics of the actual system. Unnecessary details should be avoided because they make the model difficult to understand and manage.

**2. Accuracy:**

A model should represent the important behaviour and characteristics of the actual system correctly. Incorrect assumptions or data can produce misleading results.

**3. Clearly Defined Objectives:**

Before developing a model, its purpose should be clearly identified. The model should be designed according to what we want to study, analyse or predict.

**4. Inclusion of Relevant Factors:**

Only the important components, variables and relationships that affect the system's behaviour should be included. Irrelevant details should be avoided.

**5. Flexibility:**

A good model should allow changes in input values, parameters and conditions. This makes it easier to study the system under different situations.

**6. Verification and Validation:**

The model should be checked to ensure that it is correctly developed and represents the actual system sufficiently well for its intended purpose.

- **Verification:** Checks whether the model has been built correctly.
- **Validation:** Checks whether the correct model has been built to represent the real-world system.

**7. Reliability:**

A model should produce consistent and meaningful results when the same conditions and inputs are used. Reliable models help in making better decisions.

### **4.3 Example of Modeling Principles**

Consider developing a simulation model for a bank queue.

- **Simplicity:** Include customers, cashiers and waiting queues without adding unnecessary details.
- **Accuracy:** Use realistic customer arrival and service times.
- **Clear Objective:** Decide whether the purpose is to calculate waiting time or determine the required number of cashiers.
- **Flexibility:** Allow changes in the number of cashiers and customer arrival rates.
- **Verification:** Check whether the program correctly calculates arrivals, waiting and service.
- **Validation:** Compare the simulation results with actual banking system behaviour.

This helps create a useful and reliable simulation model.
