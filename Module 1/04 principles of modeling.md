## **4. Principles Used in Modeling**

### **4.1 Introduction**

Principles of modeling are the basic guidelines or rules that should be followed while developing a model of a real-world system.

These principles help ensure that the model is simple, accurate, understandable and suitable for the purpose for which it is created.

### **4.2 Important Principles of Modeling**

**1. Simplicity:**

A model should be as simple as possible while representing the important characteristics of the actual system. Unnecessary details should be avoided because they make the model difficult to understand and manage.

**2. Accuracy:**

A model should represent the important behaviour and characteristics of the actual system correctly. Incorrect assumptions or data can produce misleading results.

**3. Clearly Defined Objectives:**

Before developing a model, its purpose should be clearly identified. The model should be designed according to what we want to study, analyse or predict.

**4. Inclusion of Relevant Factors:**

Only the important components, variables and relationships that affect the system's behaviour should be included. Irrelevant details should be avoided.

**5. Flexibility:**

A good model should allow changes in input values, parameters and conditions. This makes it easier to study the system under different situations.

**6. Verification and Validation:**

The model should be checked to ensure that it is correctly developed and represents the actual system sufficiently well for its intended purpose.

- **Verification:** Checks whether the model has been built correctly.
- **Validation:** Checks whether the correct model has been built to represent the real-world system.

**7. Reliability:**

A model should produce consistent and meaningful results when the same conditions and inputs are used. Reliable models help in making better decisions.

### **4.3 Example of Modeling Principles**

Consider developing a simulation model for a bank queue.

- **Simplicity:** Include customers, cashiers and waiting queues without adding unnecessary details.
- **Accuracy:** Use realistic customer arrival and service times.
- **Clear Objective:** Decide whether the purpose is to calculate waiting time or determine the required number of cashiers.
- **Flexibility:** Allow changes in the number of cashiers and customer arrival rates.
- **Verification:** Check whether the program correctly calculates arrivals, waiting and service.
- **Validation:** Compare the simulation results with actual banking system behaviour.

This helps create a useful and reliable simulation model.
