# **Module I – Introduction to Modeling and Simulation**

## **6. Static and Dynamic Mathematical Models**

### **6.1 Introduction**

Mathematical models represent real-world systems using mathematical equations, formulas and relationships between variables. They help us understand how different factors affect a system and predict its behaviour.

Based on whether the model considers changes over time, mathematical models are classified into **Static Mathematical Models** and **Dynamic Mathematical Models**.

### **6.2 Static Mathematical Models**

**Definition:**

A static mathematical model represents a system at a particular point in time or under a fixed set of conditions. It does not consider how the system changes over time.

These models describe the relationship between different variables using mathematical equations. They are mainly used when we want to study a system's condition without considering its time-dependent behaviour.

**Examples:**

1\. **Profit Calculation:** A business calculates its profit using revenue minus total cost. It represents the financial condition for a particular period.

\\[ Profit = Revenue - Cost \\]

2\. **Distance Calculation:** Calculating the distance between two points using their coordinates.

3\. **Population Distribution:** Calculating the population of different cities at a particular point in time.

### **6.3 Dynamic Mathematical Models**

**Definition:**

A dynamic mathematical model represents a system whose state or behaviour changes over time. It describes how different variables change and interact as time passes.

These models generally use differential equations or difference equations to represent time-dependent behaviour. They are useful for studying and predicting the future behaviour of a system.

**Examples:**

1\. **Population Growth:** Represents how the population of a particular area increases or decreases over time.

2\. **Vehicle Movement:** Describes changes in the position and speed of a moving vehicle over time.

3\. **Temperature Change:** Represents how the temperature of a room changes over time due to heating or cooling.

### **6.4 Difference Between Static and Dynamic Mathematical Models**

| Basis     | Static Mathematical Model                                          | Dynamic Mathematical Model                       |
| --------- | ------------------------------------------------------------------ | ------------------------------------------------ |
| Meaning   | Represents a system under fixed conditions.                        | Represents a system that changes over time.      |
| Time      | Time is not explicitly considered.                                 | Time is an important factor.                     |
| Behaviour | Describes a condition at a particular point or period.             | Describes changes in system behaviour over time. |
| Equations | Generally uses algebraic equations.                                | Often uses differential or difference equations. |
| Purpose   | Studies the relationship between variables under fixed conditions. | Studies and predicts time-dependent behaviour.   |
| Example   | Profit calculation.                                                | Population growth over time.                     |

### **6.5 Quick Revision 📝**

- **Static Mathematical Model:** Describes a system without explicitly considering changes over time.
- **Dynamic Mathematical Model:** Describes how a system changes and behaves over time.

**Easy trick to remember:**

- Static = Snapshot 📸 (A fixed condition).
- Dynamic = Video 🎥 (Changes over time).
