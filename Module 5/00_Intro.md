## **Topic 1: Introduction to Simulation Languages**

### **1. What is a Simulation Language?**

A **simulation language** is a programming language used to create computer models of real-world systems and study how they behave over time.

Instead of experimenting with an actual system, we create its computer model and observe its behaviour.

**Example:** We can simulate a bank with customers arriving, waiting in a queue and receiving service without actually visiting a bank.

### **2. Why do we need Simulation Languages?**

Simulation languages are used because:

1. **Save Time:** We can study a system without performing real-world experiments.
2. **Reduce Cost:** We can test different situations without spending money on actual systems.
3. **Easy Analysis:** We can calculate waiting time, resource utilization and system performance.
4. **Risk-Free Testing:** We can test dangerous or complex situations safely.
5. **Better Planning:** We can compare different system designs before implementing them.

### **3. Types of Simulation Languages**

Two important simulation languages in our syllabus are:

**A. GPSS (General Purpose Simulation System)**

- GPSS is a simulation language mainly used for discrete-event simulation.
- It represents system activities using blocks and transactions.
- It is useful for modelling queues, manufacturing systems and service systems.

**Example:** Simulating customers arriving at a bank and waiting for a cashier.

**B. SIMSCRIPT**

- SIMSCRIPT is a programming language used to develop simulation models.
- It supports event-based simulation and allows users to describe system activities through programming statements.
- It is useful for modelling complex systems.

**Example:** Simulating traffic flow, communication networks and industrial systems.

### **4. Difference Between GPSS and SIMSCRIPT**

| Basis                | GPSS                                        | SIMSCRIPT                        |
| -------------------- | ------------------------------------------- | -------------------------------- |
| Full form            | General Purpose Simulation System           | Simulation language name         |
| Approach             | Block-oriented                              | Programming-language approach    |
| Model representation | Blocks and transactions                     | Statements, events and entities  |
| Programming          | Generally simpler for standard queue models | More flexible for complex models |
| Application          | Queuing and manufacturing systems           | Complex event-based systems      |

### **5. Applications of Simulation Languages**

- Banking systems
- Computer networks
- Manufacturing industries
- Traffic management
- Communication systems
- Hospital management
- Operating systems

### **Conclusion**

Simulation languages help create computer-based models of real-world systems. GPSS and SIMSCRIPT are important simulation languages used to study system behaviour, analyze performance and solve complex problems.
