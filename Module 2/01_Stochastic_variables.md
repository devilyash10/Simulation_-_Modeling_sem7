# **Module II – Probability Concepts in Simulation**

## **Topic 1: Stochastic Variables**

### **1. What is a Stochastic Variable?**

A **stochastic variable** is a variable whose value is not fixed and depends on chance or randomness.

In simple words, we cannot predict its exact value in advance, but we can estimate the possible values and their probabilities.

It is also called a **random variable**.

### **2. Simple Examples**

Let's understand with everyday examples:

**Example 1: Tossing a Coin 🪙**

When we toss a coin, the result can be:

- Head (H)
- Tail (T)

We cannot know the result before tossing the coin. Therefore, the outcome is random.

**Example 2: Customers Arriving at a Bank 🏦**

The number of customers arriving at a bank in one hour may be:

- 5 customers
- 10 customers
- 15 customers
- 20 customers

The exact number is uncertain because customers arrive randomly.

**Example 3: Rolling a Dice 🎲**

When we roll a dice, the possible outcomes are 1, 2, 3, 4, 5 and 6. Each outcome depends on chance.

### **3. Types of Stochastic Variables**

Stochastic variables are mainly of two types:

**1. Discrete Random Variable**

A discrete random variable takes countable values, usually whole numbers.

Examples:

- Number of students in a classroom.
- Number of customers in a bank.
- Number obtained when rolling a dice.

**2. Continuous Random Variable**

A continuous random variable can take any value within a given range, including decimal values.

Examples:

- Height of a person.
- Temperature of a room.
- Time taken to serve a customer.

### **4. Difference Between Discrete and Continuous Random Variables**

| Discrete Random Variable              | Continuous Random Variable      |
| ------------------------------------- | ------------------------------- |
| Takes countable values.               | Takes any value within a range. |
| Usually represented by whole numbers. | Can have decimal values.        |
| Example: Number of customers.         | Example: Waiting time.          |
| Example: Number of students.          | Example: Temperature.           |

### **5. Importance of Stochastic Variables in Simulation**

- They help represent uncertainty in real-world systems.
- They are used to generate random events in simulations.
- They help predict possible outcomes.
- They are useful in banking, traffic management, weather forecasting and computer networks.

### **6. Quick Revision 📝**

**Remember these three points:**

- Stochastic variable = Random variable.
- Discrete = Countable values (1, 2, 3...).
- Continuous = Any value in a range (2.5, 3.7...).
